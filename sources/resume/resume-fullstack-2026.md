다양한 규모의 회사와 프리랜서를 거친 **5년 차 풀스택 개발자**로, 백엔드부터 AWS 인프라까지 직접 책임져 왔습니다.
**느린 건 빠르게, 없는 건 만들고, 반복되는 건 자동화**하는 방식으로 일합니다.

**대표 성과**
- **성능 최적화**: 글로벌 API 응답 1.2초 → 0.08초(93%↓), CRM 핵심 API 15초 → 2초(87%↓) — 병렬 처리·캐싱·CDN·다중 리전으로 병목 제거
- **AI 프로덕션 운영 설계(도구 사용이 아니라 환경 설계)**: 전자 차트 요약·시술 추천 AI 서버 1인 구축 — 개인정보(PII)를 AI에 넣기 전 비식별화하고, 신뢰할 수 있는 사내 자료에 근거해 답하도록(그라운딩) 설계해 **잘못된 답변(할루시네이션)과 AI 비용을 통제**
- **AI 개발 프로세스 설계·통제(도구 사용이 아니라 프로세스 설계)**: AI가 바로 코드를 고치지 않고 계획→사람 승인 후 진행, 조사·계획·검토 분리, 작업 기록(추적), 위험 명령 자동 차단 — 이를 위한 **로깅·차단 도구를 직접 구현**해 이슈 인지→Fix→PR(Claude Code + MCP) 파이프라인의 안정성·재현성 확보(TTC)
- **기존 서비스 단독 운영·개선(풀스택)**: 구독형 EV 서비스 1인 담당, Spring Boot → Django 마이그레이션으로 서버 지연 80%↓

- **NestJS·Spring Boot**: 헬스케어 CRM·AI 서버 설계·운영, Event-Driven 변경 이력 추적 구축
- **LLM 프로덕션화**: 개인정보 비식별화·사내 자료 근거(그라운딩)·작업 기록(로깅)으로 AI 출력의 안전성과 재현성을 통제하는 파이프라인 설계
