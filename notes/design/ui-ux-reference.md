## 핵심
유명 서비스의 UI/UX를 **모방 가능한 패턴 + 디자인 토큰 + 안티패턴** 형태로 분해한 레퍼런스. 디자인 스킬(design-consultation / design-html 등)에 "레퍼런스 + 토큰 + 적용 화면"으로 입력해 검증된 패턴을 빠르게 차용한다. 전 서비스를 관통하는 보편 원칙은 **§A 공통 원칙**, 실제 시작점은 **§B 토큰 셋**, 검수는 **§C 안티패턴**.

## 상세

### 0. 한눈에 보기 — 서비스별 한 줄 정체성

| 서비스 | 카테고리 | 한 줄 정체성 | 가장 훔칠 만한 것 |
|--------|---------|-------------|------------------|
| **토스** | 핀테크 | "금융을 가장 쉽게" — 미니멀 + 마이크로 인터랙션 | One-Thing-Per-Screen, 숫자 위계, 햅틱/모션 |
| **카카오뱅크** | 핀테크 | "친근한 은행" — 캐릭터·컬러로 금융의 차가움 중화 | 친근한 컬러/일러스트, 카드 계좌 메타포 |
| **당근** | 커뮤니티/중고 | "동네 생활" — 따뜻하고 정직한 로컬 감성 | 신뢰 신호(매너온도), 리스트 카드, 비-과시 톤 |
| **토스증권** | 트레이딩 | "주식을 토스처럼" — 복잡한 금융을 초보용으로 번역 | 트레이딩 정보 위계, 매수/매도 색, 차트 단순화 |
| **Linear** | SaaS/생산성 | "빠름이 곧 디자인" — 키보드-퍼스트, 초고밀도 | 다크 테마, 단축키, 즉각 반응, 절제된 그라데이션 |
| **Stripe** | 개발자/결제 | "신뢰의 기술 미감" — 정교한 디테일과 그라데이션 | 데이터 위계, 코드/대시보드 미감, 마이크로 디테일 |
| **Vercel** | 개발자 인프라 | "흑백의 명료함" — 극단적 미니멀, 모노톤 | 흑백 + 단일 강조, 타이포 위주, 여백 |
| **Apple** | 하드웨어/OS | "콘텐츠가 UI다" — 정직한 여백과 타이포 | 타이포 스케일, 스크롤 연출, 절제 |
| **Airbnb** | 마켓플레이스 | "신뢰와 따뜻함" — 사진 우선, 둥근 친근함 | 카드/그리드, 사진 위계, 부드러운 그림자 |
| **Notion** | 생산성 | "유연한 캔버스" — 무채색 + 블록 메타포 | 블록 UI, 무채색 베이스, 콘텐츠 우선 |
| **Arc / Raycast** | 브라우저/런처 | "도구가 즐거움" — 모션·디테일로 생산성 도구를 감각적으로 | 커맨드 팔레트, 마이크로 모션, 다크 미감 |

### 1. 토스 (Toss) — 핀테크 미니멀의 기준점
**철학**: 모든 결정이 "금융 문맹도 쓸 수 있게"로 수렴. 복잡함을 다루되 화면에선 숨긴다. One Thing Per Screen(송금=금액→계좌→확인 각각 풀스크린), 결정의 외주화(추천 금액·최근 보낸 사람 → "선택"을 "탭"으로).
**비주얼**: 화이트 베이스 + 토스 블루(`#3182F6`) 단일 강조색(액션 가능한 것만 파란색). 큰 본문(15~17pt+), 금액·잔액은 압도적으로 크게(위계=폰트 크기). 과감한 여백, 둥근 아이콘·카드.
**모션(진짜 차별점)**: 체감 0ms 피드백, 스켈레톤 로딩, 끊김 없는 전환, 숫자 카운팅 애니메이션, 핵심 순간 햅틱, 성공을 풀스크린 컨펌+애니메이션으로 성취감 전환.
**훔쳐올 것**: ① 핵심 숫자를 압도적으로 크게 ② 단일 강조색으로 "여기 누르라" 학습 ③ 위험 액션 전 재확인 화면(수취인 이름 크게) ④ 변화는 카운팅 모션으로 감각화.

### 2. 카카오뱅크 — 친근함으로 무장한 은행
**철학**: 토스가 미니멀로 쉬움을 만들면, 카뱅은 컬러·캐릭터·말투의 **친근함**으로 진입장벽을 낮춘다.
**비주얼**: 카카오 옐로 + 계좌별 컬러 카드(통장=실물 카드 메타포). 라이언 등 캐릭터로 정서적 친밀감, 에러·빈 화면도 부드럽게. 토스보다 정보 밀도 약간 높음.
**시그니처**: 컬러 통장 카드(목적별 계좌를 색으로 = 심리적 봉투/mental accounting), 26주 적금 등 게이미피케이션.
**훔쳐올 것**: ① 추상 데이터를 실물 메타포(카드/봉투)로 시각화 ② 빈 화면·에러를 일러스트로(감정 디자인) ③ 목적별 색 구분으로 분류 직관화.

### 3. 당근 — 따뜻하고 정직한 로컬 감성
**철학**: "동네 이웃 거래" → 과시 없이 따뜻함. 화려함보다 **신뢰**가 핵심 통화.
**비주얼**: 당근 오렌지(`#FF6F0F` 계열) 단일 강조 + 화이트 베이스. 정보 밀도 높은 리스트 카드(썸네일+제목+가격+위치/시간), 스캔 가능성 최우선. 생활감 있는 실사진 그대로.
**시그니처 — 신뢰 신호**: 매너온도(사람 신뢰를 게이지/숫자로), 후기·동네 인증으로 정직함 강화.
**훔쳐올 것**: ① 신뢰 지표 시각화(게이지·온도·뱃지) → 금융/트레이딩의 성과·리스크 지표에 응용 ② 정보 밀도 높은 리스트 카드 스캔 최적화 ③ 과시 없는 정직한 톤.

### 4. 토스증권 — 트레이딩을 토스답게 ⭐
**철학**: HTS/MTS의 복잡한 차트·호가창을 초보자 언어로 번역.
**비주얼**: 현재가+등락률을 가장 크게. 차트 단순화(보조지표는 토글=Progressive Disclosure). **색상 관례 주의**: 국내 상승=빨강/하락=파랑, 글로벌은 반대(상승=초록/하락=빨강). 토스의 "파란색=액션"과 충돌하므로 **등락 색 ≠ 액션 색 분리 필수**.
**시그니처**: 단순화된 라인/영역 차트 + 고급 지표 토글, 매수/매도 2버튼 + 주문 전 재확인, "이 회사 뭐하는 곳" 평이한 설명.
**훔쳐올 것(→ 트레이딩 대시보드)**: ① 현재가/수익률/PnL을 압도적 위계 ② 등락 색과 액션 색 분리 ③ 차트 기본 단순 + 고급 토글 ④ 위험 액션(매수/매도·킬스위치)은 2버튼+재확인.

### 5. Linear — "빠름이 곧 디자인"
**철학**: 속도가 UX의 본질. 모든 인터랙션 즉각 반응(옵티미스틱 UI), 마우스보다 키보드.
**비주얼**: 다크 테마 기준 + 절제된 보라/블루 그라데이션 악센트, 채도 낮은 무채색. 초고밀도 정보를 명확한 위계로. Inter 계열, 미세 보더로 영역 분리.
**시그니처**: Command palette(Cmd+K)로 모든 기능 키보드 도달, 옵티미스틱 업데이트(서버 응답 전 UI 반영), 단축키 전면 노출.
**훔쳐올 것**: ① Cmd+K 커맨드 팔레트 ② 옵티미스틱 UI ③ 다크+미세 그라데이션의 프로 도구 인상.

### 6. Stripe — 신뢰의 기술 미감
**철학**: 결제는 신뢰가 생명 → 정교한 디테일·일관성으로 "정밀함"을 증명.
**비주얼**: 시그니처 멀티컬러 그라데이션(보라-블루-청록)을 히어로·악센트에 **절제** 사용. 대시보드는 데이터 위계 교과서(요약 카드→차트→테이블), 여백·정렬 정밀. 코드/문서 미감.
**훔쳐올 것**: ① 데이터 대시보드 위계(KPI 카드→시각화→상세 테이블) ② 그라데이션은 악센트로만 ③ 포커스/호버/그림자 일관성이 신뢰를 만든다.

### 7. Vercel — 흑백의 명료함
**철학**: 극단적 미니멀. 색 거의 없이 흑백+타이포+여백으로 명료함.
**비주얼**: 모노톤(흑/백/회) + 단일 강조(검정 버튼/블루 링크). 큰 타이포, 넉넉한 여백, 선명한 대비, 기하 심볼(▲), 보더 위주 카드.
**훔쳐올 것**: ① 색을 빼는 용기(흑백+단일 강조로 고급) ② 타이포 위계·여백만으로 구조 ③ 라이트/다크 양쪽 명료함.

### 8. Apple — 콘텐츠가 UI다
**철학**: UI는 콘텐츠를 위해 사라진다. 위계·여백·타이포로 말한다.
**비주얼**: 거대한 타이포 스케일, 넉넉한 여백, 스크롤 연출(scrollytelling), 절제된 색·고품질 이미지.
**훔쳐올 것**: ① 타이포 스케일로 위계(H1과 본문의 과감한 크기 차) ② 스크롤 기반 점진 등장 ③ 덜어내기의 미학.

### 9. Airbnb — 신뢰와 따뜻함
**철학**: 낯선 사람의 집에 묵는 불안을 사진·신뢰 신호·따뜻한 형태로 해소.
**비주얼**: 사진 우선 카드 그리드, 둥근 모서리·부드러운 그림자, 코랄/핑크(`#FF385C`) 강조, 리뷰·평점·슈퍼호스트 뱃지.
**훔쳐올 것**: ① 카드 그리드+사진 위계 ② 부드러운 그림자·라운드로 친근함 ③ 신뢰 신호 배치.

### 10. Notion — 유연한 캔버스
**철학**: 도구는 중립적이어야 사용자 콘텐츠가 산다. 무채색 베이스에 콘텐츠가 주인공.
**비주얼**: 무채색(흑/회/백) 베이스+최소 강조색, 블록 메타포(모든 것이 드래그 가능, 호버 시 핸들), 이모지 아이콘으로 가벼운 개성.
**훔쳐올 것**: ① 블록 기반 구성 UI ② 무채색 베이스+콘텐츠 우선 ③ 호버 시 컨트롤 노출(평소엔 깨끗).

### 11. Arc / Raycast — 도구가 즐거움
**철학**: 생산성 도구도 감각적으로 즐거울 수 있다. 모션·디테일·다크 미감으로 "쓰는 맛".
**비주얼**: 다크 베이스+생기있는 그라데이션/글래스(블러), 풍부한 마이크로 모션, 커맨드 팔레트 중심 키보드 퍼스트.
**훔쳐올 것**: ① 마이크로 모션으로 생기(과하지 않게) ② 글래스/블러로 깊이감(레이어 위계) ③ 커맨드 팔레트+단축키.

### §A. 공통 원칙 (전 서비스 교집합) — 모방 시 최우선 적용
1. **단일 강조색 원칙**: 베이스는 무채색/화이트, 강조색 1개(많아야 2). 강조색=주목/액션.
2. **정보 위계 = 크기+대비+여백**. 색이 아니라 타이포 크기로 위계를 먼저.
3. **One Thing Per Screen / Progressive Disclosure**: 한 화면 한 목적, 고급 옵션은 펼쳐서.
4. **즉각 피드백+모션**: 모든 액션 0ms 체감 반응, 변화는 모션으로 감각화. 단, 모션은 기능적일 때만.
5. **신뢰 신호 시각화**: 평판·성과·안전을 게이지·뱃지·재확인으로 명시(금융·마켓플레이스 필수).
6. **여백은 기능이다**: 빽빽함보다 숨 쉴 공간. 밀도가 필요하면 위계로 정리(Linear).
7. **일관성 > 화려함**: 호버·포커스·그림자·라운드 값의 전역 일관성이 곧 고급스러움.

### §B. 디자인 토큰 추출 (모방용 기본 셋)
도메인에 맞춰 **강조색/색관례만 교체**하면 되는 시작점.

```
# Color
--bg-base:        #FFFFFF   (다크: #0B0B0F ~ #111114)
--bg-surface:     #F7F8FA   (카드/패널, 다크: #1A1A1F)
--text-primary:   #191F28   (거의 검정, 순검정 회피)
--text-secondary: #6B7684   (보조 텍스트)
--border:         #E5E8EB
--accent:         #3182F6   ← 단일 강조색 (도메인별 교체)
# 트레이딩 전용(액션색과 분리!)
--up:    #F04452   (국내 상승=빨강 / 글로벌이면 초록 #22C55E)
--down:  #3182F6   (국내 하락=파랑 / 글로벌이면 빨강 #EF4444)

# Typography
--font: Inter / Pretendard / SF Pro  (한글: Pretendard 권장)
--text-display: 32~40px / bold     (핵심 숫자: 잔액·수익률·현재가)
--text-h1:      24~28px / bold
--text-body:    15~17px / regular  (모바일 본문은 크게)
--text-caption: 12~13px / regular
line-height: 본문 1.5, 헤드라인 1.2

# Radius / Elevation
--radius-sm: 8px  --radius-md: 12px  --radius-lg: 16px(카드)
--shadow-card: 0 1px 3px rgba(0,0,0,.06), 0 1px 2px rgba(0,0,0,.04)

# Spacing (4px 베이스 그리드)
4 / 8 / 12 / 16 / 24 / 32 / 48 / 64

# Motion
--ease: cubic-bezier(.2,.8,.2,1)
--dur-fast: 120ms  --dur-base: 240ms  --dur-slow: 400ms
원칙: 기능적 모션만. prefers-reduced-motion 존중.
```

### §C. 안티패턴 — "AI slop" 및 흔한 실수 (결과물 검수 체크리스트)
- ❌ 강조색 남발(모든 버튼이 파랑 → 위계 죽음. 액션 1차/2차 구분)
- ❌ 그라데이션 과용(악센트로만. 전면 보라 그라데이션은 전형적 AI slop)
- ❌ 순검정/순백 + 균일 그림자(텍스트 `#191F28`로 띄우고 그림자 다층 부드럽게)
- ❌ 장식적 모션(의미 없는 바운스·회전. 모션은 상태 변화 설명 시만)
- ❌ 위계 없는 균일 카드 나열(핵심을 크게)
- ❌ 트레이딩에서 등락색=액션색 혼용(빨강이 "상승"이자 "삭제"면 치명적)
- ❌ 이모지 아이콘 남발(한두 곳 OK, 도배는 싸구려)
- ❌ center 정렬 텍스트 대량(좌측 정렬 기본)

### §D. 디자인 스킬에 넣는 법 (활용 워크플로)
1. 이 노트에서 1~2개 서비스를 레퍼런스로 지정(예: "토스 + Linear 톤").
2. §B 토큰 셋을 시작점으로 도메인 강조색/색관례만 교체.
3. 디자인 스킬에 `레퍼런스 + 토큰 + 적용 화면`을 함께 입력.
4. 산출물을 §C 안티패턴 체크리스트로 검수.
5. 트레이딩 화면이면 §4 토스증권 + §C 등락색 분리 규칙 재확인.

**적용 예시 — 트레이딩 대시보드(quant-server)**: 레퍼런스 = 토스증권(정보 위계·색관례) + Linear(다크·속도·Cmd+K) + Stripe(데이터 대시보드 위계). 홈은 총 자산/수익률을 display 사이즈 → KPI 카드 → 포지션 테이블(드릴다운). 백테스트 결과는 기본 라인 차트 + 고급 지표 토글. 위험 액션(킬스위치)은 등락색과 분리된 경고색 + 2버튼 재확인.
